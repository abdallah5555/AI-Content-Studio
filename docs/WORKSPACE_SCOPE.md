# Workspace Scope Guard

This repository is the only target for AI Content Studio development work.

## Allowed repository
- `abdallah5555/AI-Content-Studio`

## Out of scope
Do not modify, migrate, reset, delete, force-push, or reuse files from any other repository while working on AI Content Studio unless the owner explicitly requests it in the current task.

This includes, but is not limited to:
- Talabatk / Talbak Delivery repositories
- backups and experimental delivery branches
- unrelated personal repositories

## Safety rules
1. All writes must target `abdallah5555/AI-Content-Studio`.
2. API keys and secrets must never be committed.
3. Uploaded user reference media must never be committed to GitHub.
4. Reference uploads are runtime data and belong in worker temporary storage now, and object storage later.
5. Destructive operations require an explicit task-specific reason.
